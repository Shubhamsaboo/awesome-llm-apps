Restore viral McDonald's hidden-menu hacks — or invent new ones on demand — with every recipe verified against the **official McDonald's China MCP**: live store menu, real-time pricing, official nutrition table, and a value / health / taste / creativity scorecard.

- **Repo**: <https://github.com/Reak-Z/mcd-secret-menu-lab>

- **Requirements**: a McDonald's MCP token (open.mcd.cn/mcp) for live verification; the 14 pre-verified recipes work without one
- **Also includes**: DIY submission leaderboard, coupon-aware best pricing, and a pure-stdlib MCP client (80 lines)
