needle.

A new way to find.
On your own pages.

Start npm run dev from the Needle project folder, then connect to http://127.0.0.1:4199. Add your Gateway API key to the project’s .env file. Leave the access token blank for local use.

Click the Needle toolbar icon on a webpage, or press ⌘⇧F on Mac / Ctrl+Shift+F elsewhere.

Search sends the page's readable passages and your query to your server, then to Jev through Vercel AI Gateway. Chrome system pages and built-in PDF viewers are not supported. For selectable PDF text, copy it into the React app using “Bring your own text”.
